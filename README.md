# Nexus — Connection Canvas

A polished, interactive spatial workspace for turning scattered thoughts into a living system. Nexus visualizes relationships with animated connectors, signal flow, collaborative presence, and an adaptive details panel.

## Highlights

- **Living connector energy engine** — every link is a flowing gradient filament with comet pulses, sparkle trails, breathing ports and drifting signal dust, rendered in real time on canvas
- **Click any connector to surge it** — send a shockwave through a signal and refocus the canvas on its source
- Drag-and-drop nodes with live connector geometry that stays glued while you drag
- Animated directional signal flow across the graph, plus selection ripples and an intro cascade on load
- Create nodes and draw new connections interactively — new links announce themselves with a burst
- Search and command palette (`⌘/Ctrl + K`), with matching signals highlighted on the graph
- Zoom, focus, grid, story, share, and inspector controls, plus a Flow/Calm energy toggle
- Responsive desktop, tablet, and mobile layouts
- No backend or credentials required

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
